PAFFP Formatter

Create the System Upload file, the AR (payroll) and the STUB, ready to print.

1 · Masterlist files

Choose files or drag them here Excel masterlists (.xlsx). Columns can be in any order; each data sheet gets its own files.

    2 · What to create

    Add at least one masterlist.

    Upload the source workbook. Only sheets named STUB <MUNICIPALITY> (e.g. STUB HUNGDUAN) are used; other sheets are ignored. Each municipality gets the AR and the STUB as PDF (the STUB with a QR code of the RSBSA NO. in the NO column) and the System Upload as Excel.

    1 · Source workbooks

    Choose files or drag them here Excel workbooks (.xlsx) with sheets named STUB AGUINALDO, STUB HUNGDUAN, ...

      2 · What to create

      Add at least one workbook.
      Each file downloads as a .zip containing the selected outputs.
      • Every barangay starts on a new page; numbering continues to the end.
      • Files are processed in memory and are not stored on the server.
      • Print on 8.5×13 (long bond) landscape at 100% scale.
