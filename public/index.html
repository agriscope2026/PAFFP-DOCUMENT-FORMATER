PAFFP Formatter

Turn beneficiary masterlists in any column layout into the System Upload file, the AR (payroll) and the STUB, ready to print.

1 · Masterlist files

Choose files or drag them here Excel masterlists (.xlsx). Columns can be in any order; each data sheet gets its own files.

    2 · What to create

    Add at least one masterlist.
    Each masterlist downloads as a .zip containing its System Upload, AR and/or STUB Excel files.
    • Every barangay starts on a new page; numbering continues to the end.
    • Files are processed in memory and are not stored on the server.
    • Print on 8.5×13 (long bond) landscape at 100% scale.
